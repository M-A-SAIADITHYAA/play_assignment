Frontend Scaling (ISR + Edge)

Pre-renders listing pages with Incremental Static Regeneration (revalidate: 60s). 95% of traffic hits global edge cache with sub-50ms TTFB.

Search & Discovery Strategy

Change Data Capture (CDC via Kafka) replicates listing mutations from PostgreSQL to OpenSearch within 100ms for real-time geospatial search.

Concurrency & Double-Booking

Redis distributed locks (Redlock) protect availability bitsets during reservation hold; database optimistic locking prevents race conditions.

Deployment & Active-Active

Stateless containerized services run across 3 AWS Availability Zones with automated failover and zero-downtime canary rollouts.
